Arrow Escape

Untangle the lines, one arrow at a time.

Levels

How to play
  • Drag a line the way its arrow points. The rest of the line follows the head.
  • You can stop partway. Lines only move forward, so use Undo if you go too far.
  • Solid parts block each other. Dashed parts are see-through, so other lines can pass through them.
  • Slide every line off the board to finish the level. Every level can be solved.
